Data Flow:
1. Replay Plan: Pre-processed StatsBomb event data with timestamps
2. Producer: Reads events, adds metadata, sends to message broker
3. Broker: Kafka or Redis Streams, handles message persistence and distribution
4. Consumer: Receives events, logs receive timestamps
5. TTI Calculator: Matches producer and consumer events, computes latency metrics

Metrics Computed:
- TTI = t_consume - t_prod_sched
- Transport Latency = t_broker_ack - t_cons_recv
- Producer Scheduling Lag = t_prod_send - t_prod_sched
- Match Rate = (matched_events / produced_events) * 100
